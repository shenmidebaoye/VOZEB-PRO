# 快速开始

本机创作工具默认使用文件数据库：`pnpm start` 在未设置 `VOZEB_PRO_DATABASE_PROVIDER` 时自动使用 `file`。不提供 Docker / Compose 部署。

## 本机启动

环境要求：Node.js 22、pnpm 10+；短剧合成和本地转码还需要 FFmpeg。

```bash
cd web && pnpm install
pnpm start
```

可选 `web/.env.local`：

```dotenv
VOZEB_PRO_DATABASE_PROVIDER=file
VOZEB_PRO_ENCRYPTION_KEY=填写 openssl rand -hex 32 的输出
NEXT_PUBLIC_SITE_URL=http://127.0.0.1:3000
```

浏览器打开 `http://127.0.0.1:3000`。就绪后进入 `/create`，在 `/settings` 配置渠道、Skills、站点、存储与备份。

开发模式：

```bash
cd web
pnpm install --frozen-lockfile
pnpm run dev
```

文档站在 `docs/` 独立运行，固定 `http://localhost:3001`：

```bash
cd docs
pnpm install --frozen-lockfile
pnpm run dev
```

## 可选 PostgreSQL

需要时把 `VOZEB_PRO_DATABASE_PROVIDER=postgres` 和 `DATABASE_URL` 写入 `web/.env.local`，重启服务后打开 `/install` 初始化表结构。本机通常使用 `localhost:5432`。

## 首次配置顺序

1. 用 `pnpm start` 或 `pnpm run dev` 启动本机服务。
2. 在 `/settings` 配置模型渠道与默认逻辑模型。
3. 在 `/create` 分别验证文本、图片、视频和音频。
4. 按需配置本地媒体或 S3 兼容对象存储，并做一次备份导出。

下一步阅读[配置说明](./configuration)。
